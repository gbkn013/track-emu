# ADR 0002 — Datameet (CC0) as the default static timetable source

**Status:** accepted (2026-09-25) · **Touches:** AGENTS.md §11 "ask before enabling any provider other than RailRadar/Replay".

**Context.** The user asked to explore free data. Datameet/railways is CC0, offline, and needs no key, so the app works
end-to-end without spending quota.

**Decision.** Add `DatameetProvider` (static only, `supports_live=False`) and make it the default `STATIC_SOURCE`.
A Tamil Nadu EMU/MEMU extract is generated by `scripts/build_open_dataset.py` and committed.

**Consequences.** Data is ~2016, partial (130 trains), has no run-days. The API returns a `timetable_note` on every
response and the UI shows it whenever live data is absent. It is deliberately **not** presented as live under any
circumstance. When RailRadar schedule mapping is verified (Phase 0), it should become the preferred static source
and datameet the offline fallback/replay dataset.
